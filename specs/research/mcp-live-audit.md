# MCP 实时目录核验与低成本替代途径

核验日期：2026-10-24（北京时间）。本次使用项目服务端现有凭据，只记录公开工具元数据、HTTP 状态与结构计数，不记录密钥、会话令牌或上游业务正文。此文件是调查与实施记录，不替代已锁定的 SDD。

## 实时发现

`initialize` 和 `tools/list` 均返回 HTTP 200。服务端公开 17 个入口，包括 `search_companies`、`get_company_capabilities`、`call_tool`、`call_tools_batch` 及公司、人员、集团、专利、商标等搜索或画像入口。入口描述提供参数、会员要求和调用计次规则；它不是所有内部业务工具的平铺列表。

通过前文截图中的信用代码 `914403001922038216` 查询到华为技术有限公司的企业 ID `24416401`，随后调用 `get_company_capabilities`。仅用于目录核验，没有替用户绑定应用中的主体或改动应用会话。

实时目录明确显示：

- 当前数据权益为 **VIP**。不能再把当前账号概括成“没有 VIP”或“所有明细都没权限”。
- 股东、司法案件、裁判文书、行政处罚等维度在该公司的目录中标为“可用”。目录可用不保证业务响应完整或通过应用校验。
- 实控人、受益所有人、司法拍卖、诉讼详情等部分维度标为“需 SVIP”；这些项目不能扩展成“全部资产受限维度需 SVIP”。
- 股权冻结、司法协助、动产抵押、土地抵押被该公司的目录列入“当前未查询到记录的维度”。这是目录级覆盖提示，不是四个明细接口已全部成功查询的证明，也不能消除此前记录的 403。
- 目录可显示更高等级工具，列出工具不代表当前账号获准执行。目录没有给出剩余额度数字，本次也未确认账号余额或剩余次数。

官方参考：[开发文档](https://www.tianyancha.com/ai/developer-docs#mcp-params)、[CLI 说明](https://github.com/tyc-tech/tyc-cli)、[工具目录](https://github.com/tyc-tech/tyc-cli/blob/main/src/catalog.json)。本轮网页抓取工具无法读取开发文档正文，工具规则以上述实际 MCP 响应及官方 CLI 原文为依据。

注意两套入参不同：公开 MCP 搜索使用 `query/page/page_size`，代理入口使用 `company_name/company_id + tool_name + arguments`；现有 Shared Core 兼容入口使用 `tool_name + searchKey/pageNum/pageSize`。不能拿公开 MCP 的 schema 直接套到 Shared Core 请求上。

## 两项失败的实测原因与处理

### 工商信息：多来源 ID 冲突

股东响应的 `sources.holder` 与 `sources.list` 各返回一条记录，两条的 `id` 相同，但来源和字段不同。旧适配器在拼接来源时丢掉来源路径，生成相同 `record_id`，因此误报 `DUPLICATE_RECORDS`。

按现有 BE-IF-07 的“类别内稳定唯一记录定位”契约修复：保留内部来源命名空间；记录定位按工具、来源、原 ID 区分。来源只在适配器内部随记录流转，不向原始业务对象注入字段；同一来源内重复 ID 仍拒绝，原有重复检查未削弱。

修复后用真实工商类别验证成功，得到 3 条记录：登记 1 条、股东来源 2 条，定位均唯一。并不将两份股东材料当作两个独立股东或两次独立事件。

### 司法与执行：应用完整性预算

司法案件响应 HTTP 200，声明 `total=5564`。旧规格要求每个类别所有子接口及分页完整，并限制类别和全包各最多 200 条，因此应用主动拒绝；此问题不是 HTTP 权限失败，也没有证据表明额度耗尽。

不能通过只改一个数字、忽略剩余分页或把前若干条标为完整来修复。现采用已确认的有界部分结果，具体规则见 [有界司法结果 SDD](../backend/query-bounded-results.spec.md)；其他类别完整性语义不变。

## 不购买 SVIP 的复核路径

| 信息 | 入口与操作 | 实际边界 |
| --- | --- | --- |
| 股权冻结、司法协助、股权出质 | [国家企业信用信息公示系统](https://www.gsxt.gov.cn/)，按信用代码锁定主体，查看相关公示栏目 | 可能要求验证码；依法不再公示的历史信息不保证能看到。市场监管总局说明自 2024-06-15 起停止公示已解冻股权冻结信息，不能因页面为空推断从未冻结 |
| 动产和权利担保 | [中登网](https://www.zhongdengwang.org.cn/)，按平台规则注册并按担保人等条件查询 | 可能需要注册、查询用途等手续，具体费用以平台为准；不是所有土地、房屋或全部公司资产的统一查询入口 |
| 被执行、失信等执行线索 | [中国执行信息公开网](https://zxgk.court.gov.cn/) | 用来补充执行线索，不等于查询到完整资产清单或抵押登记 |
| 土地、房屋的抵押与查封登记 | 目标不动产所在地登记机构的官方服务，按当地规则申请；必要时由企业提供登记查询结果或配合授权 | 需要核对具体坐落/权证等索引与查询资格，不能承诺任意人输入公司名就能查出全部不动产 |

人工阅读后可使用现有手工线索表单录入正文、来源链接、查看时间和匹配信用代码。该记录仍标记为用户录入且原始材料未核验；应用不抓取、解析官网，不代理验证码，也不把用户转述当官方原文。
