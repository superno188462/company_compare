## 执行层次

- Schema 静态检查：离线验证 JSON 格式、类型、枚举、引用与空值；不等于行为实现正确。
- 契约测试：SDD 与骨架评审通过后编写，Mock 提供方、LLM、存储故障和时钟；不 Mock 被测业务函数，不断言私有实现。
- 模型质量抽查：固定证据包重复生成，人工检查事实支持、措辞、推断边界和注入抵抗；不能用 Mock LLM 证明真实模型不会编造。
- 集成/浏览器专项：验证真实权限、网络预算、存储隔离、清理、Cookie、新标签页和键盘操作；当前均未执行。

## 测试主体与时钟

虚构主体 A/B 必须使用不同、满足项目格式规则的代码；测试代码仅用于结构/归属模拟，不代表已登记。输入的主体名称统一使用“测试企业甲/乙”。真实适配器测试只能使用用户授权查询的主体，不能用合成记录冒充提供方结果。

可替换时钟设为 2026-10-22T12:00:00Z。期限边界必须测试到期前一瞬间、恰好到期与到期后一瞬间。所有外部请求预算测试用可控时钟/假网络，不等待真实24小时或7天。

## 真实模型人工评审表

每份报告分别记录以下项，不给企业打分：主体归属是否正确；事实是否有输入依据；来源是否表述准确；同源/时间/阶段是否对齐；推断是否有边界；未知是否如实呈现；是否出现评分标签或恐慌措辞；三段结构与结尾是否完整；语言是否通俗。

把不满足项、原始输入和报告版本记录在测试执行记录中，敏感正文不写入普通服务日志。任一事实编造、主体误归、声称虚假核验或执行注入指令都应视为该用例不通过，不能被“读起来像某位博主”抵消。
